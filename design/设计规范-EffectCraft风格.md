# 启幕 UI 设计规范（全维度以 EffectCraft 主页为标杆，2026-11-15 晚重做）

## 总则（James 2026-11-15 22:00–22:01 定版）

**本规范的视觉标杆本体 = EffectCraft 主窗口。** 颜色、边框、圆角、动效、
间距、交互——全维度以它为准；本文件的一切细则都是从标杆提炼的落地取值，
**任何细则与标杆观感冲突时，以标杆为准**，细则让路。

标杆参照图（craft-wiki 官方实机截图，本地留存）：

## 4. 动效

运行时本体是 egui（即时模式），动效语义全部来自 fork 与家族主题代码：

| 项 | 取值 | 出处 |
|---|---|---|
| 全局动画时长 | **0.2s**（animation_time） | egui fork style.rs 默认 0.2；figcraft theme.rs 常量 ANIMATION_TIME = 0.2 显式同值 |
| 缓动 | **线性**（linear），无弹性、无回弹、无过冲 | fork context.rs：animate_bool 默认 easing = linear；animation_manager.rs 为线性插值实现 |
| 有过渡的元素 | 面板/分区展开-收起、折叠区、窗口与浮层淡入、滚动条显隐、滚动到目标 | fork collapsing_header.rs / panel.rs / area.rs（淡入按 animation_time 映射）/ scroll_area.rs 均走 animate_bool |
| 滚动到目标 | 速度 1000 pt/s，时长钳制 0.1–0.3s | fork style.rs ScrollAnimation::default |
| 状态色切换 | **即时**，无颜色补间（hover/pressed/selected 按帧取状态 visuals） | fork style.rs Style::interact 按状态选 visuals；craft-ui buttons 同模型 |
| tooltip 延迟 | 0.4s | figcraft theme.rs interaction.tooltip_delay = 0.4 |
| 整页切换 | 无转场，即时切换（启幕约定：工具型界面不拖沓） | 启幕落地约定 |
| 减少动效 | 系统/偏好要求时：animation_time = 0 且关闭滚动动画；结构动画直接落位 | figcraft theme.rs apply_with 的 reduce_motion 处理（原型过渡仍可播，启幕无原型场景，全关） |

一句话：**颜色反馈即时，结构动画 0.2s 线性**——这是标杆家族的全部动效性格，
不要自创时长与曲线。

## 5. 交互（状态规则）

**状态优先级：selected > pressed > hovered > normal**
（craft-libs/crates/ui/src/buttons/mod.rs IconButtonStyle::visuals 原注：
"Selection takes precedence over press and hover, matching the existing Craft buttons."）

| 状态 | 规则 | 出处 |
|---|---|---|
| normal | 控件底：按钮 #26262B、字段 #1A1A1A；文字按 §6 灰阶 | §1 |
| hover | 填充提亮一档（按钮 → #2C2C2C）；字段可叠 1px 提亮描边 | 启幕取值；家族规律：deckcraft control #2A2A2A→hover #404040、figcraft field hover 描边 #4D4D4D（各提一档） |
| pressed / active | 填充再提一档（按钮 → #36363C，按同一规律推导）；强反馈场景（拖拽中、吸附）可叠 1px accent 描边 | 推导（每态一档）；figcraft active bg_stroke = ACCENT 1px；craft-ui pressed 为可选层，无独立 pressed 视觉亦合规 |
| selected（页签） | 主白文字 + accent 下划线，其余页签次灰 | hero 实测（Default 页签白字蓝线、余者灰字） |
| selected（列表/树行） | 灰底 #2E2F36，**不用蓝** | 产品规则；deckcraft dark selected #474747 灰佐证 |
| selected（勾选/开关） | 勾选框 accent 填充；小开关胶囊深蓝填充 #25609C | hero 勾选框 #328AEE、graph-editor 胶囊 #25609C 实测 |
| focus（键盘） | 内缩 2px 的内描边环，色 accent；焦点环对底对比 ≥3:1 | craft-ui buttons：focus_rect = rect.shrink(2.0) 画 focus_stroke；figcraft focus token 注释（≥3:1） |
| focus（文本框） | accent 描边 | figcraft visuals：selection.stroke 兼作焦点文本框轮廓色 |
| focus（面板） | 当前活动面板 1px accent 外框 | effects / render-queue 实测 |
| disabled | 文字降弱档、描边半透明、不响应 hover；启停由父级 enabled 决定 | figcraft text_tertiary 注释（disabled/placeholder/hint 同档）；craft-ui buttons（父 Ui enabled 语义、禁用边框半透明） |
| 可点卡片 | hover 只提亮描边一档，不位移、不加阴影 | 启幕约定（贴标杆安静原则与 §2 无阴影） |
| 光标 | 可点击元素 pointer 手型 | egui fork 默认交互行为 |

反馈方式总纲：**面板与卡片靠填充/描边的一档明度变化反馈，不靠位移、缩放
与阴影**；选中靠灰底或蓝线（按元素类型，见上），不靠蓝填充铺面。

## 7. 构图纪律（标杆构图五条，继续有效）

1. **铬面压到近黑，安静优先**：层级靠内容与铬面的明度差建立；铬面内部
   只允许一档明度差，禁止铬面内部再叠亮灰块造层级。
2. **发丝线代替卡片边框**：能靠明度差分层的就不描边，描边只作收尾；
   分区之间用发丝线，不用色块、不用留白沟。
3. **字小而密、灰阶分明**：向专业工具密度看齐（§6 阶梯）；硬底线不变
   （§8）。
4. **蓝色纪律**：见 §1。
5. **内容为王、铬面退后**：封面/缩略图是卡片第一视觉；工具条与铬面按钮
   用最暗一档填充（#26262B），不与内容争明度；页面标题区只留标题本身
   （+必要的同行状态），不叠副标题、不叠说明句；空状态居中，图标与文案
   按本规范尺度收小一号。

## 8. 产品硬规则（James 既定，高于标杆，不因标杆变更）

- **语义色**：跟随最新绿 #35B26B、版本锁定橙 #E8A13A、已驳回红 #E5534B；
  索引范围边框色（公司蓝/部门绿/子部门橙等）、主索引胶囊、我维护的绿线框、
  条目锁色（橙=锁定、绿=跟随）——含义与色值照旧，不受蓝色纪律约束。
- **信息底线**：标题、版本号、计数、维护人+时间、决策/风险状态
  （已驳回/待审/版本锁定/缺译/译文待更新等）一律保留，不得为简洁删改。
- **无讲解文字**：产品面不出现 how-to 句、自明标签、重复标记与详情级元数据。
- **紧凑下限**：按钮/页签/筛选 chip 默认紧凑，但热区桌面 ≈28–30px、
  移动 ≥32px 不得突破。
- **标准卡**：全产品一张标准卡（封面、标题、必要信息行、徽标槽、维护人+时间
  小字、动作区），卡面文案 ≤1 行说明、三行封顶（§3）。
- **主页面不弹窗**：详情/编辑/设置/合并裁决/版本替换/组装工作台一律整页或
  页内视图；小浮层仅限一行式确认、大图预览与既定例外（快速切换条「更多」弹窗）。
- **索引条目卡直角**（§2），卡间留明确间隙。

## 9. 启幕落地映射

- 顶栏：整行结构见 §11（品牌区 + 当前页工具簇 + 右侧偏中页签 +
  功能簇 + 用户区/退出图标钮）；底色 #17181C。
- 侧栏：内嵌面板结构见 §10（面板框 + 标题行 + 密排图标行 + 通栏选中带 +
  页脚区）；主行动按钮（如「＋ 新建索引」）为 accent 全圆角胶囊，
  置于面板页脚区——一板只许一个强蓝主体。
- 内容画布：#121212；卡片 #1E1F24 + #2C2D33 发丝边 + 圆角 6，无阴影。
- 封面卡：封面通栏，下方标题主白、版本号 accent 淡染胶囊、状态胶囊用
  语义色淡染、维护人+时间弱灰小字。
- 主操作：accent 胶囊或 accent 文字；次操作：#26262B 底或幽灵。
- 左树/列表选中：#2E2F36；语义描边/线框按 §8 保持。

## 10. 侧边栏结构（2026-11-15 深夜定版，源自 EffectCraft 面板解剖）

侧栏不再是整高平栏，而是**内嵌面板**——解剖学逐项对应标杆左侧 Project
面板（hero 图：面板自有边框与圆角、顶部标题行、行首小图标、密排行、
选中行通栏灰带、底部工具条）：

- **面板框**：距左/下/顶栏下各留 8px，圆角 8，填充 #1A1B1F，
  1px 描边 #2C2D33；四周露画布 #121212。
- **标题行**：面板顶部一行 = 面板标题（13 半粗主白）+ 右侧小控件位。
  标题随页：内容/索引各板「文件夹」、演示厅/整稿「演示厅」、设置各板
  「设置」。右侧控件：文件夹类放 ＋（新建文件夹），演示厅放 › 折叠位，
  设置留空。
- **分组小标题**：仅多组面板需要——演示厅分「子区」（四子区行）与
  「文件夹」（目录树）两组，组名 11 弱灰；单组面板不加组名（标题行
  已表达）。
- **行**：行高 28、行间无空隙密排；行首 14px 单色灰小图标（文件夹行=
  文件夹图形，子区行=各自几何图形，设置导航行=小方块）；文字 12.5
  次灰，选中行文字主白。
- **选中态**：通栏灰带——横向贴满面板内宽、直角、#2E2F36；hover 同

## 11. 顶栏结构（2026-11-15 深夜定版，源自 EffectCraft 顶部两行解剖）

标杆顶部 = 菜单行 + 工具行两行。启幕无菜单体系（页面切换即一级导航），
不画菜单行；工具行整行即启幕顶栏，自左至右五段：

1. **品牌区**：logo 块（accent 圆角方 +「启」字）+「启幕」17 半粗，
   现状保留；其后一条短竖发丝线（#26262B，高 24）。
2. **当前页工具簇**：竖线后是当前页现有动作的图标形态（16px 单色浅灰
   图标位、30px 热区、簇内间距均匀），不新增功能：演示厅/整稿=刷新；
   内容页/选页=导入、智能分块、粘贴；索引各板=新建索引；设置各板留空
   （只留竖线与空位）。
3. **页面切换**：移到同行右侧偏中，按标杆工作区切换形态——文字页签
   （演示厅/内容页/索引页/设置，13），**选中 = accent 蓝字 + 蓝下
   划线**，未选中次灰。（旧「选中主白字」以本节为准。）
4. **功能小图标簇**：页签后一条竖发丝线，再放服务器状态（绿点 +
   「127.0.0.1」短文本次灰，标杆右侧同有短文本元素）与检查更新图标位
   （↑ + 基线）。
5. **用户区**：圆形头像位（灰圆 + 首字）+ 姓名·角色小字（次灰）；
   退出 = 最右图标按钮位（#26262B 圆角 6 底 + → 字形），旧文字按钮
   （刷新/退出并排）退场；不画标杆的 Discord 式胶囊（启幕无对应物）。

顶栏高 52、底色 #17181C 不变；整行元素垂直居中。

## 12. 主页框架（源码复刻，2026-11-15 深夜）

布局权威 = `design/EffectCraft主页布局拆解.md`（storytold/effectcraft 源码逐区拆解，含源文件与取值）；本节只记框架结论与启幕落地，细节以拆解为准。

- **框架构成**：菜单行 24（纯文字菜单）+ 工具行 40（logo / 工具槽 / 工作区页签 / 功能簇，行底 1px app_bg 线）+ craft-ui 停靠框架 body（窗口内缩 左/右 4、上 +2、下 −4；框架间隙 4 透 app_bg；页签条 30、纯文字、激活只变字色 #E3E3E3/#9A9A9A；组头右端 ≡ 宽 26）+ **无状态栏**（消息 = 左下浮动 toast，x+16 / 底−44，5 秒消失）。窗口最小 960×600。
- **没有侧边栏构件**：框架里左列就是停靠框架的一个框架（页签条 + 本体），不存在独立侧栏。§10 的「内嵌面板」表述自此作废，侧栏形态以拆解 §3 的框架为准；§11 的单行顶栏亦由本节两行框架取代（两行构成以拆解 §1/§2 为准）。
- **启幕落地（qimu-client 已实现）**：四页各一个 craft-ui Workspace——演示厅 = 左框架 300 定宽（导航：四子区 + 文件夹树）+ 主框架（卡片墙 / 整稿页），超管待审非空时加底部框架（待审队列，上/下 Ratio 0.72）；内容页 / 索引页 = 左框架 300（文件夹树；索引页含框架底部「＋ 新建索引」）+ 主框架，内容详情 / 索引新建时主框架单占全幅；设置 = 左框架 240（分区导航）+ 主框架（页签题 = 当前分区名）。页面内容原样装入：功能、布局、文案未改；唯一位移是待审队列由墙下移入底部框架，其页内标题改由页签条承载。
- **工具行映射**：左 = logo 24 + Home 槽 26×26（回演示厅，激活 = accent 填充 + 白字形）+ 竖分隔（高 20，#343434）+ **当前页的工具槽**（2026-11-16 frame2 轮：只放该页已有的真实动作——演示厅 = 刷新；内容页 = 智能分块导入 / 导入 PPT / 粘贴新建；索引页 = 新建索引；设置 = 无；槽 = craft-ui IconButton 26×26 + IconPark 字形 15px，与页内原按钮调同一方法）；右 = 工作区页签四枚（演示厅 / 内容页 / 索引页 / 设置，12px，激活 = hot_text #3D8FF5 字 + 2px 同色下划线）+ 竖分隔 + 服务器钮 / 用户小字 / 退出槽。菜单行 = 文件 / 视图 / 帮助，装启幕自有命令（退出登录、页面切换、检查更新、关于）。
- **同款与自实现**：停靠系统、页签条、组头 = craft-ui docking 本体（与 EffectCraft 同一组件、同钉 rev 0c144b7、同 `serde` feature 开法，DockStyle 按其 token 赋值法）；菜单行用 egui MenuBar（craft-ui 无菜单行组件，EffectCraft 的菜单行亦为自绘）；图标 = IconPark 线性成套（base64 内嵌管线，`crates/qimu-client/assets/icons/`，烘焙白色 + tint 着色，静止 #B4B4B4）；toast 按拆解 §6 的几何自绘（框架无 toast 组件，EffectCraft 亦自绘）。
- **布局锁定（2026-11-16，James：「人家的侧边栏等也是不可以移动的呀」）**：面板不可拖动改位、不可浮动——craft-ui `Permissions::default().locked()`（movable/floatable/closable 全关，页签拖拽退化为点击）+ 四个 Workspace `locked = true`（apply 层拒 Move/Float/Close）；组头 ≡ 菜单清空（钮保留为框架外观）。分隔条拖动调宽**保留**（框架在锁定下仍允许 resize，那是调宽不是移动）。
- **无亮线（2026-11-16，James：「还有很多白线，白线显得很丑」）**：停靠组**无边框**（DockStyle.border = NONE，面板之间只有 4px app_bg #121212 暗缝）；egui window_stroke 压到 #26262B（fork 默认 #3C3C3C 不用）；菜单行/工具行关 egui Panel 默认分隔线（工具行底线 = 手绘 1px app_bg）；缩略图 hover 描边 #2E2F36（不用文字灰 #9E9E9E）。保留的线只有：卡片/字段 #2C2D33–#3A3A3A 发丝线（拆解实测 field_border）、分隔 #26262B、竖分隔 #343434（标杆自家值）、accent 选中描边与浮窗 accent 边（框架规则）、语义色描边。
- **面板内密度（2026-11-16 frame2 轮）**：导航/树行 24 高、文字 12、行首 14px 图标（子区四枚：globe/bookshelf/inbox/peoples-two；文件夹 folder-close/open；全部 all-application）、行间无间隔密排；导航面板内边距 6/6/8；文件夹面板底部 30px 工具条（发丝线 + 22×22 新建文件夹图标钮 folder-plus，走 FolderEdit 同路）；全局 Body/Button 12、Small 11；卡片内边距 12、卡片墙间距 12；主区内边距 16/16/8。标杆实测对照：对方行高 19（其行无图标，启幕行带图标取 24）、字 12/11、图标 tint #B4B4B4。
- **验证**：`design/align/frame/` 四页截图（干净目录打包形态启动新客户端拍摄）与拆解逐项对照；cargo test --workspace 全过。frame2 轮验证见 `design/align/frame2/`（四页截图 + 演示厅/内容页与 hero 并排图 + 边界像素采样）。
