# 启幕 UI 设计规范（源自 EffectCraft 实机界面，2026-11-15 James 提供截图）

来源：James 提供的 EffectCraft 0.24.1 主页截图（2880×1694），关键色值由截图采样实测；
结构与 Craft 家族共享设计语言（DeckCraft 的 ui-egui 主题为同源参考）。本规范是
「先画界面、再做软件」的依据：先在 FigCraft 里按此规范画设计稿，确认后实现。

要点：**深色打底、蓝色点睛**。蓝色只出现在：主按钮、页签下划线、图标、
选中描边、关键链接；绝不大面积铺色。选中态用灰（#3A3A3A），不用蓝填充。

## 形状与间距

- 卡片圆角 10；主按钮全圆角胶囊（高 40，圆角 20）；次级按钮圆角 8；输入框圆角 8（搜索框可全圆角）。
- 图标块：32×32 圆角 8，深蓝底 + 蓝色图形，置于卡片左侧。
- 间距：页面边距 24；卡片内边距 16；控件间距 8/12；正文字号 13，标题 20/28 半粗。
- 顶栏高约 52：左侧品牌，中间/左侧页签（文字 + 选中蓝下划线），右侧用户与操作。
- 侧栏宽约 300（设计工具）/ 启幕取 208：行高 36，选中行圆角 8 灰底。

## 启幕落地映射

- 顶栏：#1C1C1C，品牌「启幕」白字 + 蓝色方块标记；四页签白/灰字，选中蓝下划线；右侧用户·角色灰字 + 幽灵按钮。
- 内容画布：#121212；卡片 #232323 + #383838 细边 + 圆角 10，无阴影（靠边与底色差分层）。
- 封面卡：封面图通栏（幻灯片本身为亮色，与暗底形成对比），下方标题白字、版本号蓝色淡染胶囊、状态胶囊用语义色淡染。
- 主操作（登录、导出、开始演示等）：蓝色胶囊或蓝色文字；次操作：#303030 底或幽灵。
- 左树/列表选中：#3A3A3A 圆角行；我维护的绿线框、范围边框色等既有语义保持，但按暗色调亮。
