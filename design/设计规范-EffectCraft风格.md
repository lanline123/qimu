# 启幕 UI 设计规范（源自 EffectCraft 实机界面，2026-11-15 James 提供截图）

来源：James 提供的 EffectCraft 0.24.1 主页截图（两张：2880×1694 与 2880×1727），关键色值由截图采样实测（第二张复测：画布 #121212、侧栏 #232323、 raised 卡片 #282828、选中行 #3A3A3A、图标块底 #243546）；
结构与 Craft 家族共享设计语言（DeckCraft 的 ui-egui 主题为同源参考）。本规范是
「先画界面、再做软件」的依据：先在 FigCraft 里按此规范画设计稿，确认后实现。

选中描边、关键链接；绝不大面积铺色。选中态用灰（#3A3A3A），不用蓝填充。

## 构图与密度（2026-11-15 第二张实机截图复盘——与启幕现实现的差距所在）

色值与 EffectCraft 基本同源，观感差距主要在构图，不在颜色：

- **留白是第一要素**：主区内容离边缘 ≥40px（设计稿尺度），卡片间距 24–28，区块之间大段呼吸；宁可一屏少放，也不要塞满。启幕落地：页面内容内边距 24，卡片网格间距 16（egui 密度下限），区块间距 ≥20。
- **标题尺度**：页面主标题 28 半粗，副标题 13 灰；列表区有独立标题行 + 右侧过滤输入。启幕落地：页标题 22，区标题 17。
- **侧栏解剖**：顶部 = 全宽蓝色胶囊主按钮（新建项目），其下 = 全宽深灰胶囊次按钮（打开项目…），然后才是导航行（行高 36，图标 + 文字，选中灰底圆角 8）；底部有分区小标题与次要链接。启幕落地：索引页左栏顶部放全宽蓝色胶囊「＋ 新建索引」；文件夹树行高 ≥28；内容页/演示厅左栏同理（主按钮按页面语义替换）。
- **动作卡**：横向卡（左 32 图标块 + 右文字），填充 #282828（比侧栏亮一档），圆角 12，内边距 16。标准卡同理：raised 填充 #282828。
- **列表**：列头小字灰色 + 1px 细线；行与行之间靠留白和细线区分，不靠色块。
- **空状态**：居中构图——大号线框图标 + 主句（白）+ 副句（灰），四周大量留白。启幕落地：空状态居中两行，不再左上角一句话。
- **顶栏**：两行制（菜单行 + 图标工具行）是设计工具的形态，启幕不照搬；启幕保留单行顶栏（品牌 + 页签 + 用户），但页签下划线蓝、高度与留白向其看齐。

## 形状与间距

- 卡片圆角 10；主按钮全圆角胶囊（高 40，圆角 20）；次级按钮圆角 8；输入框圆角 8（搜索框可全圆角）。
- 图标块：32×32 圆角 8，深蓝底 + 蓝色图形，置于卡片左侧。
- 间距：页面边距 24；卡片内边距 16；控件间距 8/12；正文字号 13，标题 20/28 半粗。
- 顶栏高约 52：左侧品牌，中间/左侧页签（文字 + 选中蓝下划线），右侧用户与操作。
- 侧栏宽约 300（设计工具）/ 启幕取 208：行高 36，选中行圆角 8 灰底。

## 启幕落地映射

- 顶栏：#1C1C1C，品牌「启幕」白字 + 蓝色方块标记；四页签白/灰字，选中蓝下划线；右侧用户·角色灰字 + 幽灵按钮。
- 内容画布：#121212；卡片 #232323 + #383838 细边 + 圆角 10，无阴影（靠边与底色差分层）。
- 封面卡：封面图通栏（幻灯片本身为亮色，与暗底形成对比），下方标题白字、版本号蓝色淡染胶囊、状态胶囊用语义色淡染。
- 主操作（登录、导出、开始演示等）：蓝色胶囊或蓝色文字；次操作：#303030 底或幽灵。
- 左树/列表选中：#3A3A3A 圆角行；我维护的绿线框、范围边框色等既有语义保持，但按暗色调亮。
