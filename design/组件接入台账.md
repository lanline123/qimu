## craft-launcher 评估结论（第 6 步后，2026-11-15）

**结论：不接入，列为观察项。** 依据（官方说明核对）：craft-launcher 是 ArtCraft 套件的官方安装/更新启动器——从各应用的 GitHub 发布中分发其**固定目录**的 13 个套件应用（外加经官方批准的社区应用），SHA-256 校验、早期 alpha、迭代极快。启幕不在其目录内，且目录准入由 ArtCraft 团队策展（社区应用需批准 + 官方签名发布），没有自助注册面；其分发模型是公网 GitHub 发布，与启幕一期「企业局域网 + NSIS/便携包 + 局域网镜像」的分发定版正交。启幕若作其目录应用，等于改走公开发布路线，与产品定位（一期 LAN、企业内网）冲突。它唯一可迁移的思想——本机镜像模式（ARTCRAFT_LAUNCHER_DOWNLOAD_BASE，仅回环）——已由第 2 步以服务端局域网更新镜像 + craft-update 协议原生实现，无需引入。**复议触发条件**：启幕将来公开发布并与 DeckCraft 同场分发时，可申请社区应用上架，届时再评。craft-launcher-assets 是其目录应用的截图服务，随主项一并不接入。
